# Geology Exam Flashcards

A static flashcard website built from Intro to Geology notes.

## Features

- 85 curated study cards
- Chapter filter and search
- Study and quiz modes
- Shuffle, known, and needs-review tracking
- Browser-local progress storage

## Run Locally

Open `index.html` directly in a browser, or serve the folder:

```powershell
python -m http.server 5173 --bind 127.0.0.1
```

Then visit `http://127.0.0.1:5173/index.html`.
